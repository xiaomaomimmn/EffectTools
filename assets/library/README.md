## 目录命名规范

所有目录只使用小写英文与短横线，统一结构为：`英文大类/英文出处名/图片文件`。

| 后台大类 | 文件夹名称 |
| --- | --- |
| 光效 | `light-effects` |
| 序列 | `sequences` |
| 元素 | `elements` |
| 循环 | `loops` |
| 物体 | `objects` |
| 不展示 | `hidden` |

出处文件夹使用来源名称的英文 slug，例如 `kenney-particle-pack`、`fx-pixel-texture`。
